# pnpm Feature

Installs [pnpm](https://pnpm.io/) fast, disk space efficient package manager.

## Install Location

- Binary: `~/.local/share/pnpm/pnpm`
- `PNPM_HOME` set via containerEnv

## Versions

See available versions at https://github.com/pnpm/pnpm/releases

## Notes

- Requires Node.js (installsAfter nodejs-feature)
- pnpm standalone binary is a single executable that does not require Node.js at runtime
