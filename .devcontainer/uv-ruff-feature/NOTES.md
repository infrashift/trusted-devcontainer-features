# UV + Ruff Feature

Installs [Astral UV](https://github.com/astral-sh/uv) package manager and [Ruff](https://github.com/astral-sh/ruff) Python linter/formatter.

## Install Locations

- UV binary: `~/.local/bin/uv` and `~/.local/bin/uvx`
- Ruff binary: `~/.local/bin/ruff` (installed via `uv tool install`)

## Versions

- UV: https://github.com/astral-sh/uv/releases
- Ruff: https://github.com/astral-sh/ruff/releases
