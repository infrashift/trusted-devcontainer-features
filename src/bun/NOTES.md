# Bun Feature

Installs [Bun](https://bun.sh/) JavaScript runtime and toolkit.

## Install Location

- Binary: `~/.local/bin/bun`

## Versions

See available versions at https://github.com/oven-sh/bun/releases

## Notes

- Bun tarball contains a nested directory (`bun-linux-x64/`), extracted with `--strip-components=1`
- Includes bun runtime, package manager, test runner, and bundler
